**Awesome Tools** answers a simple question: *what can I actually use for free?* It collects software, websites and services that genuinely work without paying — forever-free products, honest free tiers, open-source projects you can self-host, and tools that run entirely on your own machine.

Every entry links directly to the tool's **official website or official repository**, carries an honest **free-access label**, and notes the limits that matter (usage caps, watermarks, accounts, hardware requirements, licensing).

> **Research date: October 2026.** Free plans change constantly. Always confirm current pricing, licensing and eligibility on the official site before you rely on a tool.

## About Awesome Tools

- **Direct links only.** No affiliate links, no listicles, no "top 10" filler pages — you land on the product itself.
- **Honest labelling.** A free trial is not a free plan, and free model *weights* are not a free hosted *API*. Both are labelled distinctly below.
- **Plain Markdown.** The whole directory lives in this README — browse it, search it (`Ctrl`/`Cmd + F`), or clone it.
- **Every category has a job.** AI and ordinary software live side by side, because most real work needs both.

## Free-Access Labels

| Label | What it means |
| --- | --- |
| **Free** | A genuinely free offering with no meaningful paywall for its core use. |
| **Open source** | Released under a verifiable open-source license; you can inspect, modify and usually self-host it. |
| **Free tier** | A continuing plan with real limits (usage, features, seats) — not a trial. |
| **Free credits** | Access depends on a limited or periodically refilling credit quota. |
| **Local/offline** | Runs on your own device without sending your data to a paid service. |
| **Open weights** | Model weights are published for download — this is *not* the same as an open-source license. |
| **Student offer** | Requires verified educational eligibility. |
| **Free for personal use** | Free for individuals, but commercial or organisational use needs a paid licence. |
| **Limited free** | Useful without payment, but with important restrictions worth reading. |

Labels are applied conservatively. Where a tool's free access is ambiguous, the limitation is spelled out instead of hidden.

## Privacy and Safety Notes

Tools are only useful if using them is safe. A few practical rules:

1. **Never upload secrets to an online tool.** Passwords, private keys, financial records, medical documents, passports and confidential client files do not belong in a random website's converter — no matter how convenient it looks.
2. **Prefer local processing for sensitive files.** Self-hosted or desktop tools keep data on your machine: [Stirling PDF](https://stirlingpdf.com/), [Squoosh](https://squoosh.app/), [Photopea](https://www.photopea.com/), [ExifTool](https://exiftool.org/), [VeraCrypt](https://www.veracrypt.fr/), [Cryptomator](https://cryptomator.org/).
3. **Check what "free" costs in data.** Ad-supported and venture-backed free tiers usually monetise attention, usage data or upsells. Read the privacy policy when the data is personal.
4. **Strip metadata before sharing.** Photos contain GPS coordinates and camera details. [ExifTool](https://exiftool.org/) removes them in one command; several PDF tools do the same for documents.
5. **Be suspicious of "free AI" clones.** Fake download pages, cracked software and look-alike domains are a common malware vector. Prefer the official links in this list, GitHub repositories with real stars and commit history, and app stores for mobile apps.
6. **Check extension permissions.** A screenshot tool does not need to read every page you visit. Install browser extensions only from reputable publishers with visible source code.
7. **Respect licences and commercial-use terms.** "Free to use" does not always mean "free for client work": image generators, fonts, stock media and open models frequently restrict commercial use or require attribution.
8. **Test on your own systems only.** Security tools in this directory are for defensive use and for testing assets you own or are explicitly authorised to test.
9. **Mind the upload path.** If a service must receive your file, confirm it uses HTTPS, states a deletion window, and offers an API-free local alternative when you need one.

## Choosing Between Free Tiers, Local Tools and Open Source

|  | Free tier | Local / offline | Open source |
| --- | --- | --- | --- |
| **Best for** | Trying instantly, no setup, polished UX | Sensitive data, offline work, no usage caps | Long-term ownership, customisation, self-hosting |
| **Watch out for** | Limits that tighten over time, price rises, lock-in | Your own hardware, setup time, no support | Uneven interfaces, you maintain it, licence terms |
| **Typical cost later** | Subscription | Electricity and hardware | Usually still free (support may not be) |
| **Example** | [NotebookLM](https://notebooklm.google.com/), [Canva](https://www.canva.com/) | [Ollama](https://ollama.com/), [DaVinci Resolve](https://www.blackmagicdesign.com/products/davinciresolve/) | [GIMP](https://www.gimp.org/), [Stirling PDF](https://github.com/Stirling-Tools/Stirling-PDF) |

**A simple decision path:**

1. **Is the data sensitive?** → prefer local/offline or self-hosted tools first.
2. **Will you use it daily for years?** → prefer open source or a product with a permanent free tier, not one that only gifts credits.
3. **Do you just need it once?** → a free-tier web tool is fine, and often fastest.
4. **Is hardware the limit?** → local AI and video tools need real CPU/GPU power; cloud free tiers exist precisely for that gap.
5. **Are you a student?** → check for [educational plans](#free-educational-plans-and-student-offers) before paying; many vendors give verified students full access.
