# Contributing to Awesome Tools

Thanks for helping keep this directory accurate and useful.

## Suggest a tool

1. **Search [README.md](README.md) first** (and open issues) so we don't add duplicates.
2. **Open an issue or pull request** containing:
   - The **official** website or repository URL (no affiliate links, no link shorteners, no listicles).
   - A one-sentence, specific description of what the tool actually does.
   - An **access label** from the README's label guide: `Free`, `Open source`, `Free tier`, `Free credits`, `Local/offline`, `Open weights`, `Student offer`, or `Limited free`.
   - Any limitation that matters: usage caps, watermarks, required accounts, hardware needs, licence or commercial-use restrictions.
3. **Verify free access yourself.** A free trial or one-time credit is not a free plan. If you cannot confirm the free offering, say so in the entry instead of guessing.

## Entry format

```md
- [Tool Name](https://official.example/) — What it does in one specific sentence. **Free tier · important limit.**
```

## What will be rejected

- Paid-only products, or tools whose only free access is a short trial.
- Dead projects, empty repositories, or products that no longer do what is claimed.
- Affiliate links, SEO listicles, or links that redirect through ad networks.
- Malicious, deceptive, or offensive security tooling — this list covers lawful, defensive use only.
- Inflated descriptions ("amazing", "best ever") with no useful detail.

## Fixes welcome

Corrections to broken links, outdated prices, wrong licences or changed free tiers are just as valuable as new entries. Please open a PR with a short note on what changed and where you verified it.
